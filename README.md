# Product Inventory Management System (Java)

## Project Context & Motivation
Developed contextually around the Tshwane University of Technology (TUT) 2nd-year Informatics structured programming curriculum. This system models a real-world warehouse inventory database using pure procedural structures to capture, track, optimize, and update commercial asset states.

## Core Features Illustrated
- **Interactive System Architecture:** Implements a robust state-driven `do-while` menu control loop processing distinct operational modules.
- **Dynamic State Modifications:** Features an optimized array index locator system (`updateStockQuantity`) to update tracking values dynamically on demand.
- **Synchronized Bubble Sort Processing:** Automatically sequences multiple parallel array types (Names, Categories, Prices, Quantities) matching alphabetical string weight priorities via `.compareToIgnoreCase()`.
- **Localized Business Domain Modeling:** Structured around regional retail data metrics to simulate realistic application handling conditions.
